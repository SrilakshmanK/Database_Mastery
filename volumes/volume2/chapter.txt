💼 Career Layer

Push your PostgreSQL work to GitHub with clean, meaningful commits, such as:

feat(db): create initial LMS schema
feat(db): add enrollment and lesson tables
feat(db): implement foreign key constraints
perf(db): add indexes for course search
docs(db): explain indexing strategy
feat(db): add trigger for updated_at timestamps

This repository becomes strong evidence that you can design, implement, and maintain a real relational database—not just write isolated SQL queries.
