# DB V01 — Database Fundamentals & Data Modeling

## Database Engineering Roadmap — Volume 01

---

# 0. Volume Purpose

This volume establishes the **mental model of databases** before learning PostgreSQL, MongoDB, Redis, vector databases, or database DevOps.

The goal is not to memorize SQL.

The goal is to understand:

> **What problem does a database solve?**

> **How is data represented and organized?**

> **How do we design data correctly?**

> **Why do databases behave differently from ordinary files?**

> **How do relationships, constraints, transactions, indexes, and concurrency work?**

By the end of this volume, you should be able to look at a real application and design a reasonable database before writing the first SQL query.

---

# 1. Prerequisites

You do not need previous database knowledge.

However, you should be comfortable with:

* Basic programming concepts
* Variables
* Objects/records
* Arrays/lists
* Basic file systems
* Basic computer architecture
* Basic networking concepts
* Basic backend/application concepts

The DevOps + AI roadmap already provides much of this foundation.

---

# 2. Learning Philosophy

We will learn every major concept using this progression:

### Understand

What is it?

### Explain

Why does it exist?

### Model

How does it fit into a larger system?

### Build

Use it in a lab.

### Break

Create mistakes/failures deliberately.

### Debug

Understand why it failed.

### Explain Again

Use the Feynman Technique.

The objective is **engineering understanding**, not memorization.
